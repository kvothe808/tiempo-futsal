# Tiempo Futsal

App de control de partido para el Serelles Alcoi CFS: minutos por jugador, cambios, faltas, tiempos muertos, tarjetas, análisis por partido, temporada y pizarra de jugadas.

- Se usa desde el navegador o instalada en el móvil o la tablet.
- Funciona sin conexión después de abrirla una vez.
- Los datos (partidos, temporada y jugadas) se guardan solo en el dispositivo; no se suben a ningún sitio.

**Actualizar la app:** sustituir `index.html` y cambiar `VERSION` en `sw.js`.
